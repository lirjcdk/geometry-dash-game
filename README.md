# Neon Dash

Ett färgstarkt, rytmiskt endless-runner-spel inspirerat av plattformsspel som Geometry Dash. Hoppa över hinder, samla poäng och försök slå ditt rekord.

## Spela

Öppna `index.html` i en webbläsare eller publicera repositoryt med GitHub Pages.

- **SPACE / W / pil upp / klick:** hoppa
- **P:** pausa
- **R:** starta om

Spelet använder HTML5 Canvas och sparar ditt bästa resultat lokalt i webbläsaren. All grafik är skapad med Canvas-kod och är inte kopierad från Geometry Dash.
